# Media Fallback Matrix — Concept Phase

All render concepts are intentionally static-first. This matrix defines the production requirements for any later media enhancement.

| Media use | Static baseline | Optional enhancement | Required fallback / equivalence | Placeholder restriction |
|---|---|---|---|---|
| Homepage hero | Readable proposition, logo, contact action, and nonessential abstract graphic. | Subtle directional/ambient movement. | Identical text and contact route with `prefers-reduced-motion` disabled state. | Do not rely on video to explain the offer. |
| Case-study card | Approved still image or an abstract image with evidence label. | Hover crop or short silent preview. | Full case title, context, and link remain visible and keyboard reachable. | No unapproved practice/patient image or fabricated data dashboard. |
| Case-study evidence | Textual evidence label and allowed short evidence summary. | Optional chart only when sourced and labeled. | Table/text equivalent; no color-only meaning. | No placeholder metric can resemble live performance data. |
| Team card | Rights-cleared portrait or clearly generic placeholder silhouette. | Soft hover reveal of role tags. | Name, role, short bio, and profile link remain visible without hover. | Generated portrait cannot be used as an actual employee depiction. |
| Growth-atlas connection | Reading-order text labels for every zone. | Decorative line animation. | A sequential list of zones with visible labels and links. | Do not imply a live data map or performance route. |
| Contact module | Persistent label, phone alternative, and required fields at implementation. | None required. | Functional keyboard/touch form with errors and confirmation. | Never request or log patient information. |
