# Propel Dental — Full Homepage Concept Renders

This companion package provides **three full-scroll homepage design concepts**, each delivered as a desktop and mobile render. Every existing homepage and shared-footer copy block is retained verbatim, including **Book a Strategy Call** as the primary call to action. The current `logo.svg` asset is placed in each header and footer.[1] [2]

| Concept | Visual intent | Desktop | Mobile |
|---|---|---|---|
| **A — Evidence Ledger** | A dark, structured operating dossier with a ledger-like hero, high-contrast proof cards, and staged program modules. | `homepage-concept-a-desktop-full.png` | `homepage-concept-a-mobile-full.png` |
| **B — Practice Story** | A warm editorial approach with paper tones, navy sections, expressive typography, and a more relationship-led rhythm. | `homepage-concept-b-desktop-full.png` | `homepage-concept-b-mobile-full.png` |
| **C — Growth Atlas** | A deep blue-green, systems-led view that uses four connected hero objectives and modular capability sections. | `homepage-concept-c-desktop-full.png` | `homepage-concept-c-mobile-full.png` |

## Content boundary

The following content is **not** introduced in these homepage images: case-study copy, team profiles, fabricated outcomes, testimonials, practice names, patient imagery, or new claims. The existing homepage and footer content are deliberately preserved. The case-study and team-profile expansion remains a future, separate information-architecture layer defined in `CONCEPTS-AND-TEMPLATES.md`.

## Render characteristics

| View | Output behavior |
|---|---|
| Desktop | Full-scroll 1600 px-wide PNG showing the header, hero, every homepage section, final contact section, and footer. |
| Mobile | Full-scroll 430 px-wide PNG with a deliberate single-column reflow; no desktop grid is simply scaled down. |
| Copy treatment | Current homepage and shared footer text transcribed from the checked-out repository. |
| Logo treatment | Existing `client/public/images/logo.svg` source asset in header and footer. |
| Production boundary | These are static review images only. They do not constitute a website implementation, deployment, or public content approval. |
