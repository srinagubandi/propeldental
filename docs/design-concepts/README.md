# Propel Dental — Design Concept Package

This versioned, **design-only** package contains three divergent desktop/mobile directions for expanding the Propel Dental website with case studies, team profiles, and reusable templates. It does **not** implement a website, modify production, alter Railway, change public copy, or approve any performance or clinical claim.

## Review order

1. Start with [`CONCEPTS-AND-TEMPLATES.md`](CONCEPTS-AND-TEMPLATES.md) to compare the three directions and the proposed case-study/team templates.
2. Review the matching six renders in [`renders/`](renders/).
3. Use [`BASELINE-AND-RETENTION.md`](BASELINE-AND-RETENTION.md) to preserve public substance before a future implementation.
4. Review the proof, media, QA, and release-preparation records before approving real content.

## Non-negotiable content boundary

All body copy in the visual concepts is **Latin placeholder text**. Placeholder portraits, abstract images, and evidence labels are illustrative only. Before implementation, replace them only with approved team bios and photos, rights-cleared assets, and substantiated practice-case evidence. Do not use the current public site’s performance claims, testimonials, or named practices as automatically approved proof.
