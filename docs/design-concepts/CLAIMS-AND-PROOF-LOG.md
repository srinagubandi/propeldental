## Evidence label specification

Every published proof item should expose the smallest useful evidence label. The exact visual treatment varies by concept, but the information must remain available without hover or motion.

| Field | Example state in concept phase | Production requirement |
|---|---|---|
| Evidence type | `Evidentia illustrativa` | `Client-approved case study`, `Verified operational metric`, or precise equivalent. |
| Source / owner | `Recensio pendens` | Name the accountable source or owner where appropriate. |
| Review date | `—` | Show a current review date. |
| Scope | `Exemplum tantum` | State timeframe, context, and what the evidence does not establish. |
| Limitation | `Nulla mensura...` | Include any material methodology, cohort, or confidentiality limitation. |
